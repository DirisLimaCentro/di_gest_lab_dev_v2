1. RESUMEN EJECUTIVO

El presente documento describe el plan de trabajo para la implementación de dos módulos funcionales en el sistema de gestión de laboratorio: (1) Flujo completo para el examen Hemoglobina Glicosilada (HbA1c) — Código 83036, replicando la arquitectura del flujo PSA existente; y (2) Módulo de mantenimiento para la gestión de Grupos de Derivación por Dependencia, que permitirá configurar dinámicamente qué establecimientos de origen derivan muestras a qué laboratorio de destino según convenios vigentes.

8. SUPUESTOS Y RESTRICCIONES
  • Se dispone de 1 desarrollador full-stack dedicado al proyecto con conocimiento del sistema existente.
  • El servidor de desarrollo local usa XAMPP con PHP ≥ 7.4 y PostgreSQL ≥ 12.
  • El entorno de producción tiene la misma versión de PHP y PostgreSQL que el entorno de desarrollo.
  • Las estimaciones de horas no incluyen capacitación al usuario final ni elaboración de manuales.
  • El flujo de HbA1c es idéntico en lógica al de PSA — solo cambian: id_producto, estructura del Excel de resultados, y firmas del PDF.
  • No se requiere autenticación adicional ni cambios en el sistema de sesiones actual.
  • El buffer del 10% cubre: correcciones de bugs en pruebas, ajustes de interfaz y coordinación.
  • Los despliegues a producción se realizan vía git pull desde el repositorio GitHub configurado.
